EasyTrace5000 Parameter Guide

Every field, its range, its default, and what it changes

Reading This Page

Parameters are grouped by the step they appear in, then by the section heading they sit under in the panel. That is the order you meet them in the app: Source Geometry before you generate offsets, Z Strategy before the preview, Feeds & Toolpaths before the toolpaths.

Four columns are worth explaining:

Values
The range the field accepts, or the options in the dropdown. Out-of-range entries are rejected by the form rather than clamped silently.
Default
What a fresh operation starts with. Tool-derived fields have no default - they are seeded from the tool you pick.
Applies to
Which operations show the field. A field you cannot find is usually one that belongs to a different operation type.
Shown when
Several fields are conditional and only appear once another setting is on, or set to a particular value. If a parameter is documented here but missing from your panel, this is why.

The machine filters the form too

Some parameters only exist on one kind of machine. A field marked with a machine does not appear on the others - the laser fill settings never show up on a router operation, and depth and feed never show up on a laser one. Where nothing is marked, the field is a router one.

The same text is in the app

Every description below is the tooltip text for that field - hover the ? beside any label to get it in place. This page and the app read from the same string pack, so they cannot drift apart.

For what each operation does, see the Operation Guide. For how the stages fit together, see How a Job Works.

Machine settings are not on this page

Post-processor, safe and travel Z, rapid feed, units, PCB thickness, line numbers, tool length compensation and laser spot size are job-wide rather than per-operation. They are covered in the Machine Settings Reference.

Clearing Strategy

ParameterValuesDefaultApplies toWhat it does
Clearing Strategy
Machine class: laser		 Offset Paths - Concentric, streak-proof / Filled Polygon - Laser software controls fill / Hatch Fill - Directional line coverage Offset Paths - Concentric, streak-proof Copper Isolation, Copper Clearing How the laser fills areas that need copper removal. • Filled Polygon: Exports solid shapes - your laser software handles the fill pattern. SVG only. • Offset Paths: Concentric paths shrinking inward. Most reliable for streak prevention. • Parallel Hatch: Straight lines at a fixed angle. Fast but single-direction. • Hatch: Perpendicular sets of lines. More passes shift the angle between each other.
Pass Spacing Mode
Shown when Clearing Strategy is Offset Paths - Concentric, streak-proof or Hatch Fill - Directional line coverage
Machine class: laser		 Step Over % / Lines per cm / Lines per inch Step Over % Copper Isolation, Copper Clearing Choose how to define the distance between consecutive laser passes. Step Over uses a percentage of spot size. Lines/cm and LPI set the density directly.
Step Over
Shown when Clearing Strategy is Offset Paths - Concentric, streak-proof or Hatch Fill - Directional line coverage and Pass Spacing Mode is Step Over %
Machine class: laser		 10 - 99 % 50 Copper Isolation, Copper Clearing Percentage of the spot diameter that adjacent paths overlap. Lower values (more overlap) give better copper removal but increase processing time. 50% is a good starting point; reduce to 30% if streaks appear.
Lines per cm
Shown when Clearing Strategy is Offset Paths - Concentric, streak-proof or Hatch Fill - Directional line coverage and Pass Spacing Mode is Lines per cm
Machine class: laser		 1 - 1000 lines/cm 200 Copper Isolation, Copper Clearing Number of laser passes per centimetre. Higher values produce denser coverage.
Lines per Inch
Shown when Clearing Strategy is Offset Paths - Concentric, streak-proof or Hatch Fill - Directional line coverage and Pass Spacing Mode is Lines per inch
Machine class: laser		 5 - 2540 lines/inch 508 Copper Isolation, Copper Clearing Number of laser passes per inches. Higher values produce denser coverageance.
Hatch Passes
Shown when Clearing Strategy is Hatch Fill - Directional line coverage
Machine class: laser		 1 - 8 2 Copper Isolation, Copper Clearing How many hatch passes to run. Each additional pass is rotated from the base angle, so coverage evens out instead of streaking along one direction.
Hatch Angle
Shown when Clearing Strategy is Hatch Fill - Directional line coverage
Machine class: laser		 0 - 180 ° 45 Copper Isolation, Copper Clearing Angle of the hatch lines in degrees. For parallel hatch, lines run at this angle. For cross-hatch, the second set runs perpendicular (angle + 90°). 45° is a good default - it crosses both horizontal and vertical traces.

Cut Settings

ParameterValuesDefaultApplies toWhat it does
Cut Side
Machine class: laser		 Outside / Inside / On Line Outside Board Cutout, Drill Where the laser kerf falls relative to the board outline. • Outside: Laser cuts outside the line (board stays full size). • Inside: Laser cuts inside the line (board shrinks by kerf). • On Line: Laser follows the exact line (board shrinks by half the kerf on each side).

Stencil Output

Registration Margin

Machine class: knife		 0 - 2 mm 0 Stencil Rounds each aperture corner so a drag knife or vinyl cutter can follow it. A radius smaller than the cutter compensation comes out square, because a round cutter cannot cut a corner tighter than itself.

Z Strategy

Cut Depth -10 - 0 mm -0.1 Copper Isolation, Copper Clearing, Board Cutout, Drill, Stencil Final target depth for all cuts, relative to the material surface (Z=0). Should be a negative value (e.g., -0.05mm).

Entry Method
Shown when Mill Holes is on		 Plunge / Helix Helix Drill How the cutter enters an oversize hole. Helix spirals down and loads the tool gently; Plunge drops straight in and needs a centre-cutting bit.

EasyTrace5000 Parameter Guide

Every field, its range, its default, and what it changes

Reading This Page

Parameters are grouped by the step they appear in, then by the section heading they sit under in the panel. That is the order you meet them in the app: Source Geometry before you generate offsets, Z Strategy before the preview, Feeds & Toolpaths before the toolpaths.

Four columns are worth explaining:

Values
The range the field accepts, or the options in the dropdown. Out-of-range entries are rejected by the form rather than clamped silently.
Default
What a fresh operation starts with. Tool-derived fields have no default - they are seeded from the tool you pick.
Applies to
Which operations show the field. A field you cannot find is usually one that belongs to a different operation type.
Shown when
Several fields are conditional and only appear once another setting is on, or set to a particular value. If a parameter is documented here but missing from your panel, this is why.

The machine filters the form too

Some parameters only exist on one kind of machine. A field marked with a machine does not appear on the others - the laser fill settings never show up on a router operation, and depth and feed never show up on a laser one. Where nothing is marked, the field is a router one.

The same text is in the app

Every description below is the tooltip text for that field - hover the ? beside any label to get it in place. This page and the app read from the same string pack, so they cannot drift apart.

For what each operation does, see the Operation Guide. For how the stages fit together, see How a Job Works.

Machine settings are not on this page

Post-processor, safe and travel Z, rapid feed, units, PCB thickness, line numbers, tool length compensation and laser spot size are job-wide rather than per-operation. They are covered in the Machine Settings Reference.

Machine Settings

These apply to every operation. The defaults are the app's: a post-processor's setup can start a field at its own value, or lock it while it is selected. A post-processor's own fields, such as its start and end blocks, appear under it.

G-code Units
Shown when the post-processor supports it
Machine class: router		 Millimeters (G21) / Inches (G20) Millimeters (G21) Sets the units for the exported G-code file (G21 for mm, G20 for inches).
Line Numbers (N)
Shown when the post-processor supports it
Machine class: router		 on / off off Prefix G-code blocks with line numbers (N10, N20…). Shown only when the post-processor's control accepts them.
Line Number Step
Shown when Line Numbers (N) is on
Shown when the post-processor supports it
Machine class: router		 1 - 1000 10 Increment gap between consecutive line numbers (N words). A step of 10 outputs N10, N20, N30… leaving space to insert manual blocks at the machine controller.
Tool Length Offset
Machine class: router		 None / Controller tool table (G43 Hn) / Controller tool table, H from T (Tn M06 G43) / Measured at change time (controller macro) (as the post-processor offers) set by the post-processor Where the controller gets the new tool's Z length after a change. 'Controller tool table' assumes you have measured each tool into the control's offset table. 'H from T': the control takes the offset register from the T word. 'Measured at change time' means a controller macro probes the tool and owns Z, so no G43 is emitted. 'None' emits nothing and you re-zero Z on the new bit yourself.

4th Axis

SettingValuesDefaultWhat it does
Machine Rotary Axis
Machine class: router		 A - along workspace X / B - along workspace Y A - along workspace X Which machine axis the rotary turns about: X gives an A word, Y a B word. It is how the rotary is mounted, so every 4th-axis operation uses it, and changing it marks them for regeneration. Only words the post-processor declares can be exported.
Chuck Side
Machine class: router		 Low end (toward -X / -Y) / High end (toward +X / +Y) Low end (toward -X / -Y) Which end of the rotary axis the chuck holds. Each operation's chuck-end boundary settings apply at that end, and its tail-end ones at the other.
4th-Axis Route
Machine class: router		 Rotary word (A/B in degrees) / Rotary word (A/B in arc mm) / Axis replacement (Y carries arc length) (as the post-processor offers) set by the post-processor How the 4th axis reaches the machine. 'Rotary word' sends A or B and drops Y - the CAM does the wrapping - in degrees, or in millimeters of arc for a rotary calibrated in linear units. 'Axis replacement' keeps Y carrying millimeters of arc at the reference radius, for a rotary wired to the Y driver with steps/mm calibrated. Only routes your post-processor declares are offered.
Index Settle Dwell
Machine class: router		 0 - 5 s 0 Pause after each index rotation, before the tool re-enters the material, so a belt-driven rotary can settle. Starts at the post-processor's value; servo or geared rotaries generally need none.

Laser Output

SettingValuesDefaultWhat it does
Laser Software
Machine class: laser		 Generic, LaserGRBL, xTool Studio, LightBurn, RDWorks / Ruida xTool Studio The program you will open the exported file in. It decides how layers are grouped, whether colors encode passes, and which palette is used.
Laser Spot Size
Machine class: laser		 0.01 - 1 mm 0.02 The effective cut width of your laser beam. Manufacturer should list it in the specification sheet. Typical values: UV laser 0.02-0.08mm, Fiber laser 0.03-0.15mm.
Export Format
Machine class: laser		 SVG - Vector / PNG - Raster Image SVG - Vector SVG exports vector paths that laser software (LightBurn, RDWorks) interprets with its own power/speed settings per color layer. PNG exports a raster image at the specified DPI - useful for direct image engraving modes.
Export DPI
Shown when Export Format is PNG - Raster Image
Machine class: laser		 100 - 4000 DPI 1000 Resolution of the exported PNG image. Higher DPI gives finer detail but larger file size. 1000 DPI is suitable for most PCB work. Match this to your laser software's engraving resolution setting.

Clearing Strategy

ParameterValuesDefaultApplies toWhat it does
Clearing Strategy
Machine class: laser		 Filled Polygon - Laser software controls fill / Offset Paths - Concentric, streak-proof / Hatch Fill - Directional line coverage Filled Polygon - Laser software controls fill Isolation Routing, Copper Clearing How the laser fills areas that need copper removal. • Filled Polygon: Exports solid shapes - your laser software handles the fill pattern. SVG only. • Offset Paths: Concentric paths shrinking inward. Most reliable for streak prevention. • Parallel Hatch: Straight lines at a fixed angle. Fast but single-direction. • Hatch: Perpendicular sets of lines. More passes shift the angle between each other.
Laser Spot Size
Shown when Clearing Strategy is Offset Paths - Concentric, streak-proof or Hatch Fill - Directional line coverage
Machine class: laser		 0.01 - 1 mm — Isolation Routing, Copper Clearing Read-only reminder of the spot size set in Machine Settings, where it is changed. Offset and hatch strategies space their passes from it.
Pass Spacing Mode
Shown when Clearing Strategy is Offset Paths - Concentric, streak-proof or Hatch Fill - Directional line coverage
Machine class: laser		 Step Over % / Lines per cm / Lines per inch Step Over % Isolation Routing, Copper Clearing Choose how to define the distance between consecutive laser passes. Step Over uses a percentage of spot size. Lines/cm and LPI set the density directly.
Step Over
Shown when Clearing Strategy is Offset Paths - Concentric, streak-proof or Hatch Fill - Directional line coverage and Pass Spacing Mode is Step Over %
Machine class: laser		 10 - 99 % 50 Isolation Routing, Copper Clearing Percentage of the spot diameter that adjacent paths overlap. Lower values (more overlap) give better copper removal but increase processing time. 50% is a good starting point; reduce to 30% if streaks appear.
Lines per cm
Shown when Clearing Strategy is Offset Paths - Concentric, streak-proof or Hatch Fill - Directional line coverage and Pass Spacing Mode is Lines per cm
Machine class: laser		 1 - 1000 lines/cm 200 Isolation Routing, Copper Clearing Number of laser passes per centimetre. Higher values produce denser coverage.
Lines per Inch
Shown when Clearing Strategy is Offset Paths - Concentric, streak-proof or Hatch Fill - Directional line coverage and Pass Spacing Mode is Lines per inch
Machine class: laser		 5 - 2540 lines/inch 508 Isolation Routing, Copper Clearing Number of laser passes per inch. Higher values produce denser coverage.
Hatch Passes
Shown when Clearing Strategy is Hatch Fill - Directional line coverage
Machine class: laser		 1 - 8 2 Isolation Routing, Copper Clearing How many hatch passes to run. Each additional pass is rotated from the base angle, so coverage evens out instead of streaking along one direction.
Hatch Angle
Shown when Clearing Strategy is Hatch Fill - Directional line coverage
Machine class: laser		 0 - 180 ° 45 Isolation Routing, Copper Clearing Angle of the hatch lines in degrees. For parallel hatch, lines run at this angle. For cross-hatch, the second set runs perpendicular (angle + 90°). 45° is a good default - it crosses both horizontal and vertical traces.

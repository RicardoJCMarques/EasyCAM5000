# Getting help

*Looking to support the project financially? That's
[Ko-fi](https://ko-fi.com/eltryus) and the
[sponsorship section](./README.md#sponsorship). This page is about getting
unstuck.*

## Start with the documentation

Most questions are answered there, and it's kept closer to the code than
anything else.

* **EasyTrace5000** — [CNC guide](https://cam.eltryus.design/easytrace5000/doc/cnc) · [Laser guide](https://cam.eltryus.design/easytrace5000/doc/laser) · [Operations](https://cam.eltryus.design/easytrace5000/doc/operations) · [Parameters](https://cam.eltryus.design/easytrace5000/doc/parameters)
* **EasyShape5000** — [Workflow guide](https://cam.eltryus.design/easyshape5000/doc/guide) · [Operations](https://cam.eltryus.design/easyshape5000/doc/operations) · [Parameters](https://cam.eltryus.design/easyshape5000/doc/parameters)

Every parameter also has a tooltip in the app with the same text.

## Questions

[**GitHub Discussions**](https://github.com/RicardoJCMarques/EasyCAM5000/discussions)
— machine settings, post-processor choice, "how do I do X", "is this output
right". Please use Discussions rather than the issue tracker; it keeps answers
findable for the next person with the same question.

## Bugs and requests

[**Issue tracker**](https://github.com/RicardoJCMarques/EasyCAM5000/issues/new/choose)
— pick the Bug, Accessibility or Feature template. For bugs, attach the file
that triggers the problem and console output from `enableTraceDebug()` or
`enableShapeDebug()`.

## Security

Do not open a public issue. Use
[private vulnerability reporting](https://github.com/RicardoJCMarques/EasyCAM5000/security)
— details in [SECURITY.md](./SECURITY.md).

## Response times

This is a one-person project maintained around other work. I read everything.
Bugs with a reproduction file get looked at first, because they're the ones I
can actually act on.

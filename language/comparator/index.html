i18n Translation Comparator

This tool compares, validates, edits, and exports language packs for the EasyCAM5000 Suite.

Workflow

  • Select or Drop: Choose presets from the headers or drag JSON files directly onto the columns.
  • Direct Editing: Click any field in the right column to translate or adjust text. Plural objects expand into dedicated category fields.
  • Validation: Badges show what the apps would refuse or ignore: changed {tokens} or tags, empty values, a plural without {count} in the source, and plural forms the language uses but the pack lacks.
  • Not listed: meta, the pack's identity, and output.gcode: G-code comments are always English.
  • Auto-Saving: Changes save locally as working drafts per target language until exported or reverted.

Shortcuts & Controls

  • Up / Down Arrows: Navigate through table rows.
  • ↶ Button: Revert a modified key back to the loaded file version.
  • Export Diff: Download a sparse JSON containing only modified keys.
  • Export Full: Download the whole pack in English key order, without empty values.
